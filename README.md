# yserdev site

Frontend estático preparado a partir dos arquivos públicos fornecidos pelo projeto.

## Estrutura

- `index.html` — página principal.
- `assets/app.js` — lógica do frontend.
- `assets/main.css` — estilos.
- `manifest.json` — manifesto da aplicação.

Para executar localmente, sirva esta pasta com qualquer servidor HTTP estático e abra o endereço indicado pelo servidor.

> Este repositório contém apenas os arquivos públicos do frontend; não inclui backend, banco de dados ou credenciais.

## Publicação

O projeto pode ser publicado por GitHub Pages ou outro serviço de hospedagem estática após a configuração do diretório raiz como fonte do site.
